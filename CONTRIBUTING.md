# Contributing

Issues and pull requests are welcome.

- Run the app: `npm start`
- Run the tests: `npm test` (needs Chrome or Chromium; set `CHROME=/path/to/chrome` if it is not `google-chrome`)
- No build step. Edit files in `docs/` directly.
- Keep the app dependency-free and fully usable offline.
- New UI text goes in both the `ar` and `en` dictionaries in `docs/app.js`.
